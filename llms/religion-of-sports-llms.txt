# Religion of Sports

> Religion of Sports is an Emmy Award-winning sports media and entertainment production studio
> founded in 2017 by Tom Brady, Michael Strahan and Gotham Chopra, operating as
> The Religion of Sports Media, Inc. out of Santa Monica, California. It produces premium
> non-fiction film, documentary series and branded content for Netflix, HBO, Paramount+, ESPN,
> Apple TV+, Showtime, Fox Sports and NBC Sports.

## No API surface

Religion of Sports publishes **no public API**. As of 2026-08-26 there is no developer portal,
no API reference, no SDK, no webhook catalog, no MCP server and no A2A agent card. Contract
discovery was run against the only public host (www.religionofsports.com) and every candidate
path returned HTTP 404: /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json,
/api-docs, /docs, /redoc, /graphql, /llms.txt, /sitemap.xml, and all seven probed
/.well-known/ documents. The host api.religionofsports.com does not resolve in DNS.
Do not attempt to call an API here; there is none to call.
